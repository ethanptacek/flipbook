Put it on your site

Two lines of code, any platform

Everything is static — HTML, CSS, images. It runs on WordPress, Squarespace, Shopify, Webflow, or a plain HTML page, with no build step and no third-party requests. Paste one of these where you want the book to appear.

Recommended. The book resizes itself to the container and switches between a two-page spread and single pages as the space allows. 

<div data-warning-lites-flipbook></div>
<script src="__BASE__embed.js" defer></script>

For page builders that strip <script> tags. Set the height yourself — the ratio below suits most full-width containers. 

<iframe
  src="__BASE__flipbook.html"
  title="Warning Lites 2026 Product Catalog"
  width="100%" height="820"
  style="border:0;border-radius:14px"
  loading="lazy" allow="fullscreen" allowfullscreen></iframe>

Options

Tune it without touching the code

Set these as data- attributes on the container for the script embed, or as query parameters on the iframe URL (flipbook.html?page=7&theme=light).

OptionValuesDefaultWhat it does
page1–211Page the book opens on.
themedark · lightdarkColour of the reader chrome around the pages.
modeauto · spread · singleautoTwo-page spread, one page, or pick by width.
heightpixels—Fixed height. Turns auto-sizing off. script embed only
min-heightpixels420Floor for auto-sizing. script embed only
max-heightpixels900Ceiling for auto-sizing. script embed only
radiuspixels14Corner radius of the embed. script embed only

Deep links

Every page has its own address. Link straight to the cone spec sheet with flipbook.html?page=13 — the copy-link button in the reader gives you the address of whatever is on screen.

Driving it from your page

The script embed exposes a small API on window:

WarningLitesFlipbook.goto(13);
WarningLitesFlipbook.next();
WarningLitesFlipbook.onPage(function (page, total) {
  console.log(page + ' of ' + total);
});
